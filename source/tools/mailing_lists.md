# Mailing lists


All the lists are moderated by CCRES team.

To use the list add `@listes.ipsl.fr` to the name of the list.

| Lists            | Usage                                     |
| ---------------- | ----------------------------------------- |
| actris_crs       | Any people interested in CCRES activities |
| actris_crs_nf    | PIs of CCRES NFs                          |
| ccres_contact    | To contact CCRES CF                       |
| ccres_disdro_cal | Disdrometer calibration working group     |
| actris-ccres_hkd | HKD working group                         |
| ccres_team       | Members of CCRES units                    |
